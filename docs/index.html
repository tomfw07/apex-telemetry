FIELD NOTES / 001

How to read an F1 telemetry comparison

Telemetry traces are most useful when read together. Speed shows the car's velocity; throttle shows accelerator input; brake channels indicate brake state where available. Aligning laps by distance helps compare what happened at roughly the same point on track.

A trace is not a complete explanation of performance. Driver inputs, tyre condition, fuel, traffic, setup, weather and track evolution can all matter—and public data does not expose every team measurement.

This is an evergreen guide, not a report about a particular race or driver.
